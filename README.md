# 🚛 Sistema de Controle de Pátio e Gestão de Cargas

Aplicação backend desenvolvida em **Java** com conexão a banco de dados **MySQL** via JDBC, projetada para controle operacional de fluxo de veículos e cargas em pátio logístico.

---

### 🛠️ Tecnologias e Conceitos Aplicados

* **Linguagem:** Java (Conceitos de POO e Lógica Estruturada)
* **Arquitetura:** Padrão DAO (Data Access Object)
* **Persistência / Conexão:** JDBC (Java Database Connectivity) & MySQL
* **Ambiente de Execução:** Console / Terminal

---

### ⚙️ Funcionalidades

* Cadastro e controle de veículos/caminhões (placas, motoristas e status operacional).
* Registro e conferência de cargas e mercadorias.
* Gestão de movimentações e permissões de usuários.
* Operações completas de CRUD conectadas diretamente ao banco de dados relacional.
